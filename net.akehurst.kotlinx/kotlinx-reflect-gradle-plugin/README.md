# kotlinx-reflect Gradle plugin

The Gradle plugin for [kotlinx-reflect](../kotlinx-reflect/README.md). It uses
[KSP](https://github.com/google/ksp) to generate the code that registers your classes with
kotlinx-reflect, so that reflection works on JS, Wasm and Native as well as the JVM.

```kotlin
// build.gradle.kts
plugins {
    kotlin("multiplatform") version "2.4.0"
    id("net.akehurst.kotlinx.kotlinx-reflect-gradle-plugin") version "<version>"
}

kotlinxReflect {
    // globs of classes to register for commonMain (and tests); they may be in this module or in dependencies
    forReflectionMain.set(listOf("com.example.model.*"))
    // extra globs for tests only (commonTest)
    forReflectionTest.set(listOf("com.example.testmodel.*"))
}
```

Then call `KotlinxReflectForModule.registerUsedClasses()` once before using reflection.

The plugin adds the `kotlinx-reflect` dependency and applies and configures KSP itself. It generates:

- for `commonMain`: `<module>_commonMain.KotlinxReflectForModule`, from KSP's common metadata compilation;
- for `commonTest`: `<module>_commonTest.KotlinxReflectForModule`, which registers the `commonMain`
  classes and then the test classes, generated by KSP once per test target.

`<module>` is the Gradle project name with every character other than a letter or digit replaced by `_`.

See the [kotlinx-reflect README](../kotlinx-reflect/README.md) for globs, third-party libraries, what
gets registered, the API, and migrating from the older compiler-plugin versions.
